# Đặt hàng quán Cafe

### Overview
* Xem menu đồ uống / bánh ngọt.
* Chọn món, tạo đơn và tính tiền.
* Lưu và đọc dữ liệu món/đơn hàng qua file text (`.txt`).

### Technology
* Java (JDK 17+)
* Java Swing (Kéo thả trong netbeans)
* Lưu trữ: File I/O (`data/menu.txt`, `data/orders.txt`,`users.txt`)
